== Changelog

What changed in idna in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#idna-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Added the library: internationalized domain names over Unicode 17.0.0 tables.
* Added Punycode encoding and decoding, into a caller's buffer or a pmr string.
* Added UTS 46 ToASCII and ToUnicode, passing every line of IdnaTestV2.
* Added IDNA2008 validity of labels and domains, with its contextual and Bidi rules.
* Added errors as values with a fixed category, and options for every check.
* Added the `WEBCPP_IDNA_NO_EXCEPTIONS` configuration macro, which
`WEBCPP_NO_EXCEPTIONS` also defines.
// end::unreleased[]
